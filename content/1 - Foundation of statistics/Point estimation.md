### Concept
- *Motivation:* The primary goal of statistical analysis is to draw inferences about the unknown parameters, using observed statistics
- *What is the point estimation:* The process of using a statistic to calculate a single value which is to serve as a "guess" of the unknown parameter value
- *What is the point estimator:* A statistic used for estimating the value of an unknown parameter $\theta$. It is called a **point estimator** of $\theta$ and often denoted as $\hat{\theta}$.
- *What is the point estimate:* The number calculated by applying the estimator $\hat{\theta}$ on the sample data
### Property
#### Point estimator
- [[Bias|Unbiased]]
- [[Efficiency|Efficient]]
- [[Consistency|Consistent]]
### Practice
- The point estimator is a function of the [[Random sample|random sample]]. It depends on the sample size, $n$. Sometime, it is denoted as $\hat{\theta}_{n}$
### Caution
- $\hat{\theta}$ refers to the sample statistic that can be observed from the sample *i.e.* a tool ; $\theta$ refers to the population parameter that is unobservable *i.e.* the target
