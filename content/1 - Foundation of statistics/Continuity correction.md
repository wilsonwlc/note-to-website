### Concept
- *When to use it:* use a [[Continuous random variable|continuous]] distribution to approximate a [[Discrete random variable|discrete]] distribution by [[Central Limit Theorem (CLT)|Central Limit Theorem (CLT)]]
- *Why we need it:* have more accurate approximation
### Practice
| Case         | Improved version   |
| ------------ | ------------------ |
| $P(X \le c)$ | $P(X \le c + 0.5)$ |
| $P(X < c)$   | $P(X < c - 0.5)$   |
| $P(X \ge c)$ | $P(X \ge c - 0.5)$ |
| $P(X > c)$   | $P(X > c + 0.5)$   |
- $c \in \mathbb{Z}$
