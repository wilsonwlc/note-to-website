### Concept
- *What is it:* a [[Random variable|random variable]] whose possible values are uncountable and which has a probability density function
### Definition
A random variable $X$ is called a continuous random variable if 
there exists $f:\mathbb{R} \rightarrow [0, \infty)$ such that $$F(x) = P(X\leq x) = \int_{-\infty}^{x} f(t) dt$$
- $-\infty < x < \infty$
- $f$ is called [[Probability density function (pdf)|Probability density function (pdf)]]
### Caution
- The rigorous definition requires **Lebesgue measure**
